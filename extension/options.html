Text Explain（划词解释）

本机 DeepSeek Harness（推荐） 连着电脑上的 DSH 插件。三档讲法由它提供，还能联网搜索，并把整段问答 交接给一个新会话。需要 DSH 正在运行。
我自己的 API 接任意 OpenAI 兼容接口：DeepSeek、OpenAI、Gemini、智谱、Kimi，或本机的 Ollama / LM Studio。不需要装 DSH；但没有「联网搜索」（那是 DSH 提供的能力）， 交接改为复制一份 Markdown。
标「免费」的是服务商自己提供的免费层——去它官网注册就能拿到 Key，不花钱。 智谱 GLM-4.7-Flash 是国内直连且长期 0 元的那个，最适合日常划词解释。 本机 Ollama / LM Studio 则完全免费、数据不出电脑。
⚠️ 免费服务的三点提醒：① 有限速（具体数值在服务商控制台看）；② 免费模型会换代（旧版下线后请求自动路由到新版，模型名可能要改）；③ 注意隐私——免费服务通常会用你的数据改进模型，敏感内容请改用本机模型或自己的付费 Key。

按服务商的叫法填，例如 deepseek-chat、gpt-4o-mini、llama3.1。
