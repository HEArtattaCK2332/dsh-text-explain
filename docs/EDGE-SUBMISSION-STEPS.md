# Edge 上架操作手册（照着做即可）

> **给谁看**：不熟悉开发者后台的人。每一步都写"点哪里、填什么、会看到什么"。
> **总耗时**：填表约 20–30 分钟；审核 1–7 个工作日。**免费**。

显示 `In Progress` 即审核中，只能等（个人账户通常几天）。

> 实战（2026-10-12）：草稿全部填妥、安装包也验证通过，唯独卡在这一关。
> 好消息是——**验证期间可以先把草稿建好、包传完、表单填满**；等它一变绿，回来点「发布」即可。

## 第 3 步：新建扩展并上传安装包

1. 左侧或首页点 **「扩展」**（Extensions）
2. 点 **「新建扩展」**（New extension）
3. **上传安装包** → 选择：
   ```
   E:\DSH-cj\dsh-text-explain\dist\text-explain-chrome.zip
   ```
4. **等待上传与解析**（包很小，29.5 KB，几秒钟）
5. **会看到**：一个表单，左侧有若干分区（属性 / 隐私 / 商店一览 / 提交）

> 上传后若提示「与已存在的扩展重复」，忽略即可（那是第一次上传前的提示，正常提交即可）。

## 第 4 步：填「属性」（Properties）—— 直接粘贴


### 简短描述（Short description，有字数上限）

```
选中一段话，右键就得到讲解；讲多浅多深由你挑，还能追问、联网查证、把整段问答交给 AI 继续。
```

### 详细描述（Description）

```
读文章遇到看不懂的段落，以前要复制、切到 AI、粘贴、再补一句「讲浅一点」——来回好几步。
这个扩展把这条路缩成一步：选中 → 右键 → 出结果。

它自带三档讲法，因为「不懂」也分深浅：
· 小白 —— 完全不懂 AI、不懂代码的人
· 通识 —— 会用电脑、有常识，但没学过这一行
· 专业 —— 同行：术语直接用，讲机制、取舍与边界
浮窗里能随手切档，切了当场重讲同一句。

还有这些：
· 追问 —— 带着上下文接着问，不必重述背景
· 网页语境 —— 自动附上所在小节的标题与段落，折叠显示不占地方
· 联网 / 本地查证 —— 让它当场查一趟，查完只补充新东西；查不到会明说「我查了但没找到」
· 一次答不满意？换档或联网后，上一次的回答会折叠保留，可对照不丢
· 交接 —— 把整段问答整理成 Markdown，开一个新会话悄悄放好

两种连法：
· 本机 DeepSeek Harness（推荐）—— 连着电脑上的 DSH 插件，能用它的联网与本地查找
· 我自己的 API —— 接任意 OpenAI 兼容接口（DeepSeek / OpenAI / Gemini / 智谱 / Kimi，
  或本机的 Ollama / LM Studio）。这个模式完全不需要安装别的东西。

默认只在右键菜单里出现，不打扰您读文章；也可以改成「划词浮出小按钮」。
```

## 第 5 步：填「隐私」（Privacy）—— 直接粘贴

若问「是否收集或使用个人数据」：

**答案：否 / No**（不收集、不传输到任何服务器）

若要求一段说明文字：

```
本扩展不收集、不存储、不传输任何用户数据到开发者或第三方服务器。

您选中的文字只会在您主动点击「解释」时，发送到以下两者之一：
1) 您本机运行的 DeepSeek Harness（127.0.0.1:3080），或
2) 您在设置中自己填写的 API 地址（例如您自己的 DeepSeek / OpenAI 账号）。

设置（含 API Key，若填写）通过浏览器扩展存储保存在本机，不会上传。
本扩展不使用任何远程加载的代码。
```

---

## 第 6 步：填「权限说明」—— 直接粘贴

Edge 会要求解释每条权限的用途。逐条粘贴：

| 权限 | 说明文字 |
| --- | --- |
| `storage` | 保存用户自己的设置（默认讲法、后端地址、API Key 等），只存在本机浏览器里 |
| `contextMenus` | 提供「用大白话解释『选中的文字』」右键菜单项，这是本扩展的主要入口 |
| `http://127.0.0.1:3080/*`、`http://localhost:3080/*` | 与本机运行的 DeepSeek Harness 通信（它监听本机 3080 端口）。仅回环地址，不涉及外部网络 |
| `https://*/*`、`http://*/*`（可选权限） | 仅当用户选择「我自己的 API」模式并填写某个接口地址时，浏览器才当场询问是否授权那一个域名。扩展不会预先获得全网权限 |

## 第 7 步：上传截图

**位置**：表单里的 **「商店一览」/「Store listing」** 分区。
**做法**：点「添加图片」/ 拖拽，上传您拍好的截图。

**尺寸要求**：**1280×800** 或 **640×400**（PNG/JPEG）。
**至少 1 张**，建议 3 张（解释效果 / 追问中 / 设置页）。

> 若提示尺寸不符：用 Windows「画图」打开 → 「重新调整大小」→ 取消勾选「保持纵横比」→ 填 1280 与 800 → 保存。

## 第 8 步：设置可见性并提交

1. 找到 **「可见性」/「Visibility」** → 选 **「公开」/「Public」**（否则别人搜不到）
2. 检查没有红色必填项
3. 点 **「发布」/「提交」**（Publish / Submit）

**会看到**：状态变成 **「审核中」/ In review**。

- **通过后**：扩展会出现在 <https://microsoftedge.microsoft.com/addons> ，可用关键词 `Text Explain` 搜到

## 出问题时的排查

| 现象 | 怎么办 |
| --- | --- |
| 后台打不开 / 白屏 | 换浏览器（Edge 或 Chrome），或稍后重试；这个站点在国内通常可直连 |
| 上传后报错 | 确认用的是 `text-explain-chrome.zip`（**不是** firefox 那份） |
| 提示版本冲突 | 在后台把旧的草稿删掉，或把 `extension/manifest.json` 的版本号 +0.0.1 后重新打包 |
| 卡在某个字段不知道怎么填 | 把那个字段的**提示原文**发我，我给出该填什么 |

## 附：实战踩坑记录（2026-10-12 首次提交）

按实际绊住人的顺序记下。下次照此避雷。

### 1. 清单里有 `key` 字段 → 上传直接被拒

```
程序包验证失败: 该清单不应包含 key 字段。 Line: 0 Column: 0
```

`key` 是 Chrome 用来固定扩展 ID 的公钥，**Edge 商店不收**。上传前从 `manifest.json` 删掉。
> 副作用：去掉后扩展 ID 会变，本机已装开发版的设置（API Key 等）可能需重填。
> 原清单（含 key）已备份到 `docs/manifest.with-key.bak.json`。

### 2. 打包务必用「白名单」，**不可**整目录压缩

`extension/` 目录里混着开发文件，一律**不能进包**：

- `extension-key.txt`（**含密钥**）
- `build-firefox-manifest.cjs`
- `manifest.firefox.json`
- `README.md`、`STORE-SUBMISSION.md`

正确做法：只挑运行时文件（`manifest.json`、`background.js`、`content.js`、`markdown.js`、`styles.js`、`options.html`、`options.js`、`icons/`）另存到中转目录再压缩。
> 实测：整目录压缩得 45 KB（裹进 5 个开发文件）；白名单打包得 33 KB、11 个条目。

### 3. 账户验证是硬门槛

见文首「第 0 步」。草稿能建、包能传、表单能填，唯「发布」被拦——**不是操作问题**。

### 4. 语言只有「英语(美国)」，且「添加语言」是灰的

包内没有 `default_locale` 与 `_locales/`，Edge 把语言识别为 `en-US`，且不给添加别的语言。
不影响上架。若想让商店页归入中文语区，需给包加 `_locales/zh_CN/messages.json`，并把 manifest 的 `name` / `description` 改成 `__MSG_xxx__` 占位符后重新上传。

### 5. `content_scripts` 匹配 `<all_urls>` 的理由要自己找地方写

后台「隐私」页只让为 `storage`、`contextMenus` 与主机权限逐条写理由，**`<all_urls>` 注入没有单独的位置**——建议并入「主机权限理由」一并说明（本次已写）。

### 6. 「认证说明」别漏，这是过审的关键一栏

提交页最后的「认证说明（Notes for certification）」。审核员机器上没有本机 DSH 服务，不说清容易被判「功能不可用」。建议照抄：

> 本扩展默认连接本机 `127.0.0.1:3080` 的 DeepSeek Harness 服务。审核时若本机无此服务，请点击浏览器工具栏的扩展图标进入设置页，将后端切换为「我自己的 API」，填入任意 OpenAI 兼容接口地址与 Key（如 `https://api.deepseek.com/v1`）即可完整测试：在任意网页选中文字 → 右键 →「用大白话解释」。扩展不需要登录、不收集数据，所有设置仅存本机。

### 7. 截图：一个图位一次只能传一张，重复上传是「追加」

「屏幕截图」的文件框不是多选框，一次一张；同一图位再次上传会**追加**（最多 6 张）。
尺寸必须 **1280×800** 或 **640×400**（PNG/JPEG）。

### 8. Partner Center 的两处「唬人」路径

- `/dashboard/microsoftedge` 有时渲染成**通用主页**（「我的访问权限」空着、没有 Edge 卡片）——不代表没注册，直接进 `/dashboard/microsoftedge/overview` 反而能看到后台。
- 点「入门 / Get started」若跳到 `enrollnow/error/msedgeaddons/AlreadyEnrolled`，那是**已注册**的提示，不是报错；照它说的去「帐户设置」即可。

### 9. 反爬会拦「无头浏览器」

Partner Center 走 Akamai 防护，`HeadlessChrome` 一律回 `Access Denied`（连站点根域都拦）。
若要用程序代劳，须以**正常启动的浏览器**（可加 `--remote-debugging-port`）接管，UA 正常即可通行。
